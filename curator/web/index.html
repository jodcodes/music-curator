🎵 Metadata Enrichment

Was es tut: Füllt fehlende Metadata-Felder in deinen lokalen Audio-Dateien — BPM, Genre, Release Year, Composer und Cover Art.

Quellen: MusicBrainz (primär), AcousticBrainz (BPM), Discogs (Genre), Wikidata, Last.fm (Tags). Cover Art aus CoverArtArchive, Spotify, Last.fm, Discogs.

Smart Strategy: Pro Feld wird nur so lange gesucht, bis eine Quelle es liefert — ca. 50% weniger API-Calls. Bereits angereicherte Tracks werden bei späteren Läufen übersprungen.

⚠ Nur für heruntergeladene Dateien (uploaded/matched). Cloud-only Tracks werden übersprungen. Schreibt nur year, bpm, genre, composer in die Datei-Tags.

🎭 Mood Analysis (4 Tempers)

Was es tut: Klassifiziert deine Playlists in 4 emotionale Kategorien und verschiebt sie in entsprechende Ordner in Apple Music.

Woe — Melancholie, Trauer, Introspektion
Frolic — Freude, Energie, Celebration
Dread — Angst, Anspannung, Dramatik
Malice — Wut, Aggression, Intensität

Wie es funktioniert: Pro Track wird Name, Artist, Album und Genre an OpenAI geschickt (modell: gpt-4.1-nano). Die KI gibt Temperament + Confidence zurück. Danach wird die ganze Playlist anhand der Track-Ergebnisse klassifiziert.

Ordnerstruktur: 4 Tempers / <Genre> / <Temper> — z.B. 4 Tempers / Electronic / Woe. Bestehende Ordner werden wiederverwendet.

⚠ Benötigt OpenAI API Key. Kosten: 1 API-Call pro Track + 1 pro Playlist. Nur macOS.

Hold Ctrl/Cmd to select multiple

📂 Organize Playlists

Was es tut: Klassifiziert Playlists nach Genre und verschiebt sie in Genre-Ordner in Apple Music.

Wie es funktioniert: Pro Track werden Genre-Tag, Artist-Matching und Text-Normalisierung ausgewertet. Die Ergebnisse werden zu einem Playlist-Score aggregiert. Ein TF-IDF-Fallback greift, wenn das primäre Scoring unklar ist. Wenn ein Track kein Genre-Tag hat, wird MusicBrainz/Discogs befragt.

Genre-Kategorien: Hip-Hop, Electronic, Jazz, Rock, Disco/Funk/Soul, World, und mehr. Konfigurierbar via data/config/genre_map.json.

⚠ Dry-Run zeigt zuerst, was passieren würde. Bestehende Ordner werden wiederverwendet. Nur macOS.

ⓘ Playlist organization requires macOS. Metadata enrichment is available on all platforms.

❤️ Fav Songs Curation

Was es tut: Sortiert die "Favourite Songs"-Liste in Genre-Subplaylists innerhalb einer "Fav Songs"-Ordnerstruktur.

Wie es funktioniert: Jeder Track aus Favourite Songs bekommt ein Genre (aus dem Track-Tag, kanonisch gemappt) und ein Temperament (Keyword-Matching: "dark/dread/night" → Dread, "sad/lonely" → Woe, "rage/hard" → Malice, sonst → Frolic). Danach wird pro Genre eine Playlist ♥ <Genre> im Fav Songs-Ordner erstellt und der Track dorthin kopiert.

Temperament hier: Simples Keyword-Matching — keine KI, keine API-Kosten. (Für KI-basierte Stimmungsanalyse siehe Mood Analysis.)

Safety: Preview-Modus zeigt erst was passieren würde. --apply führt Changes aus. Smoke-Test macht einen reversiblen Einzeltrack-Test vor dem echten Apply. Bestehende Ordner/Playlists werden wiederverwendet.

⚠ Nur macOS. Tracks ohne Genre-Tag gehen zu "Sonstige".
